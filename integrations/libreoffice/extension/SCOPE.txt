REPORT-GEN: OPTIONAL LIBREOFFICE ADAPTER / ADAPTADOR OPCIONAL

ENGLISH
This extension requires LibreOffice with its Python UNO component provider.
It changes line breaking only for ASCII technical literals of at least 24
characters (32 for URLs) containing a digit, underscore, slash or colon, explicitly marked
with the private language tag zxx-ZZ-x-rgwrap. "zxx" means nonlinguistic content;
"ZZ" is the Unicode CLDR unknown region. Ordinary prose keeps its language.

The extension registers a specific locale service. It does not replace the
general qlt or Unicode break iterator, change font sizes, add invisible
characters, insert manual line breaks, rewrite text or change hyperlink targets.
Other operations delegate to LibreOffice's normal Unicode iterator.

Build without installation:
  python integrations/libreoffice/build_oxt.py --output report-gen-literals.oxt

Install the OXT explicitly through LibreOffice's Extension Manager and restart
LibreOffice. Installation is optional and never performed by the builder.
The DOCX remains editable without this adapter, but ordinary LibreOffice may
then wrap the marked literals earlier. This is not a portable DOCX-only fix.
Text typed after a technical run should retain the surrounding prose language.

This adapter does not certify native Microsoft Word, screen readers, every
Unicode script, PDF clipboard extraction or PDF URI normalization. LibreOffice
may normalize percent-encoded unreserved URI characters when exporting a PDF.
The document's visible literal and DOCX hyperlink target remain independent of
that PDF behavior. Uninstalling the extension restores the original renderer.

ESPANOL
Esta extension necesita LibreOffice y su proveedor de componentes Python UNO.
Solo ajusta literales tecnicos ASCII de al menos 24 caracteres (32 en URL) con digitos,
guion bajo, barra o dos puntos, marcados expresamente zxx-ZZ-x-rgwrap. No cambia
el texto, los destinos de enlaces ni el idioma de la prosa. No agrega caracteres
invisibles, saltos manuales o reducciones de letra.

La instalacion es opcional mediante el administrador de extensiones; despues
de instalar, reinicia LibreOffice. El constructor nunca instala automaticamente.
El DOCX sigue siendo editable sin el adaptador, aunque pueden reaparecer los
saltos anticipados. No es una correccion universal para cualquier editor.
Al escribir despues de un literal, conserva el idioma de la prosa circundante.

No certifica Word de escritorio, lectores de pantalla, todos los alfabetos,
el copiado desde PDF ni la normalizacion de destinos URL en el PDF de LibreOffice.
La desinstalacion devuelve el comportamiento original del motor.
